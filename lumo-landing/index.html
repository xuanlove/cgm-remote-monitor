常见问题

你可能想知道

还有其他问题？写信到 hello@lumo.team，我们通常在一小时内回复。

Lumo 支持哪些会议与协作工具？

目前支持飞书、腾讯会议、Zoom、Google Meet、Microsoft Teams 的会议接入，以及飞书、Slack、Notion、GitHub、Jira 的双向同步。企业版还可以通过开放 API 接入内部系统。

我的数据安全吗？

所有数据在传输中使用 TLS 1.3 加密，静态数据使用 AES-256 加密。我们已通过 SOC 2 Type II 审计，并支持数据区域选择、细粒度权限与完整审计日志。企业版可私有化部署，数据不离开你的环境。

AI 会用我们的数据训练模型吗？

不会。默认情况下，你的内容仅用于为你提供服务，不会用于训练任何公共模型。企业版可签署专门的数据处理协议，并支持完全关闭跨租户的模型优化。

可以从其他工具迁移过来吗？

可以。我们支持从 Notion、Confluence、飞书文档批量导入，历史会议记录也可以通过 CSV 导入。迁移过程中原数据不受影响，你可以随时对照。

如何取消订阅或导出数据？

在「设置 - 计费」中可随时取消，取消后服务保留至当前周期结束。所有内容支持导出为 Markdown、JSON 与 CSV，导出入口在「设置 - 数据」中，一键打包下载。
